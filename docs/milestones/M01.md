The three cancellation tests failed against the previous implementation (temporarily restored for this check) and pass with the fix; the two genuine-failure tests pass with both. Cancellation during the operation is simulated at the EF Core connection-opening boundary via an interceptor; cancellation mid-way through SqlClient's network handshake is not deterministically testable and was observed only in manual probes.
